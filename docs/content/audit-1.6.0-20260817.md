| `transformer-padding-mask` NaN 서술 | 지적이 과함. fp16에서 `-1e9`는 오버플로해 `-inf`가 되므로 두 구현이 실제로 분리되지 않는다. 원문은 "무너질 수 있어"로 헤지했다 |
| `transformer-mixture-of-experts` 보조 손실 | 지적이 틀림. DeepSeek-V3도 보조 손실을 버리지 않았고, 원문은 "보조 손실이나 용량 제한"으로 병렬 제시했을 뿐이다 |
| `agent-tool-output-context-budget` 절단 표시 | 한국어 구문 오독. "A해야 B할 수 있다"는 필요조건 구문이지 보장이 아니다 |

## 1. 확실한 오류 (1건)

### `agent-memory-summarization-loss` — 인과가 뒤집혔다

- 원문: "요약을 요약하면 오류가 누적됩니다. **그래서** 매번 새로 요약하기보다 이전 요약과 새 대화만으로 갱신하는 방식 (…) 을 씁니다."
- 문제: "이전 요약 + 새 대화" 갱신은 `S_t = f(S_{t-1}, ΔC_t)`이고, 전개하면 원본까지의 거리가 턴 수만큼 쌓이는 완전한 재귀다. 즉 앞 문장이 지적한 바로 그 구조를 처방으로 제시했다. 반대로 매번 원본 전체를 다시 요약하면 원본에서 항상 1홉이라 누적이 없다(비용만 크다). keyPoints는 "요약의 재요약은 오류 누적을 일으킴"이라 두 번째 문장만 반대 방향을 가리킨다.
- 수정: "그래서 요약을 다시 요약하는 사슬을 길게 만들지 않는 것이 핵심입니다. 구간별 요약을 원문에서 한 번씩만 만들어 계층으로 쌓고 필요한 구간만 펼치는 방식이 대표적이며, 이전 요약에 새 대화를 이어 붙이는 방식은 비용은 싸지만 매 턴 재요약이 쌓이므로 원문을 다시 참조할 경로를 함께 남겨야 합니다."

## 2. 수정할 정밀도 문제 (7건)

| 문항 | 문제 | 수정 |
|---|---|---|
| `math-convexity-saddle-point` | convex는 최솟"값"이 같음을 보장할 뿐 최소"점" 유일성은 strictly convex여야 한다. 이 문항의 followUp이 초기값-해 관계를 묻는다 | "같은 곳에" → **"같은 최솟값에"** |
| `dl-diffusion-model` | CFG를 조건 주입 경로처럼 서술. CFG는 반영 강도를 조절하는 기법이다 | "cross-attention 등으로 주입하고 classifier-free guidance로 반영 강도를 조절하며" |
| `rag-embedding-truncation-normalize` | keyPoints "내적·유클리드는 단위 길이를 전제"가 문맥 없이 암기된다. 전제가 아니라 동치 조건이다 | keyPoints → "모든 벡터가 단위 길이일 때만 내적·유클리드 순위가 코사인과 일치하므로 절단 후 재정규화" |
| `transformer-label-smoothing` | "부작용"이 calibration과 한 문장에 붙어 "LS가 calibration을 해친다"로 오독될 여지. 문헌은 ECE 개선을 보고한다(EN-DE 0.056→0.019) | "확신도의 절대 수준이 눌려 임계값을 다시 맞춰야 하는데, ECE 같은 지표는 오히려 개선되는 것이 보통이고" |
| `transformer-mixture-of-experts` | "전체 파라미터는 전문가 수만큼" — 복제는 FFN뿐이라 약 24% 과장(Mixtral 8×7B = 46.7B, 8배면 57.9B) | "복제된 FFN 몫이 전문가 수만큼 불어나 전체 파라미터는 크게 늘지만" |
| `transformer-weight-tying` | "그만큼"의 선행사가 "두 행렬"로 읽혀 절감량 2배 과장 | "그중 한 행렬 분량을 통째로 줄일 수 있습니다" |
| `system-llm-service-difference` | 초선형 비용의 메커니즘이 빠져 트래픽 자체로 오귀인할 여지 | "특히 멀티턴에서는 매 턴 이전 대화를 다시 보내므로 대화가 길어질수록" |

선택 사항: `system-llm-as-judge`에 "모든 쌍을 비교하면" 한정어 추가.

## 3. 말투 — AI 지문은 번역투가 아니라 금형이다

번역투 지표는 61문항 통틀어 2회뿐이다("~에 대한" 1, "~을 통해" 1). 어휘는 깨끗하다. 문제는 구조의 균일함이다.

| 항목 | 수치 |
|---|---|
| shortAnswer가 정확히 2문장 | **60 / 61** |
| 종결어미 `-ㅂ니다` 평서형 | **61 / 61, 예외 0** |
| 40자 미만 짧은 문장 | 123문장 중 **8개(6.5%)** |
| 두 번째 문장이 "그래서"로 시작 | 14회 |

사람이 61번 말하면 어떤 건 한 문장으로 끝나고 어떤 건 네 문장이 된다. 그 흔들림이 0이라는 것이 최대 징후다.

### 길이 초과 19건

기계 검사가 전부 잡았다. 최장은 `dl-rnn-lstm-gates` 195자, `dl-autoencoder-vae` 187자, `ml-svm-margin-kernel` 164자.

### 기준 자체의 문제

한국어를 소리 내면 초당 5~6음절이므로 **135자는 약 18~22초**다. 화면 문구는 "10초 핵심 답변"이고, shortAnswer 중앙값은 126자다. **평균 20초짜리를 10초 답변이라 부르고 있다.**

선택지:
- (a) 상한 90자로 조이고 세 번째 문장을 심화로 내린다 — 대부분 재작성
- (b) 화면 문구에서 "10초"를 뺀다 — 콘텐츠 유지
- (c) 상한 120자로 조인다 — 작성 규칙의 "10~20초"에 정렬

### 리듬 처방

문장 수 쿼터(1문장 25% / 2문장 45% / 3문장 30%), 40자 미만 문장 비율 6.5% → 20%, "그래서" 14회 → 4~5회, 종결어미 3~4종 혼합, 문항 첫 어절을 `[주제어]은/는` 일변도에서 동작·상황 시작으로 3분의 1 전환.

## 4. 범용성 — 공개 불가 판정

### 구조적 사실

`prerequisites` 필드는 **런타임에서 전혀 쓰이지 않는다**(`grep -rn "prerequisite" src/features src/App.tsx` → 0건). 저작하고 CI에서 순환 검사까지 한 뒤 버려진다. 덱은 순수 랜덤 셔플이고 세션 길이 상한이 없다.

### 신규 61문항이 사다리를 악화시켰다

난이도 분포는 foundation 7 / intermediate 34 / advanced 20이고, **transformer·llm·rag·agent·math에 기초를 0개 추가**했다. 기초 3개는 ai-system, 4개는 ml/dl이다.

| 카테고리 | 기초 | 배경 없이 읽을 수 있는 문항 | 신규 기여 |
|---|---:|---:|---|
| transformer | 3 | 1 | 기초 0 / 심화 7 |
| rag | 2 | **0** | 기초 0 |
| agent | 1 | **0** | 기초 0 / 심화 4 |
| llm | 4 | 1 | 기초 0 |
| ai-system | 3 | 3 | **기초 3 — 유일하게 고친 곳** |

### 덱 도달성 결함

- "AI 기초" 목표 + 입문자 = 15문항인데 **6개(40%)가 덱 밖 선수를 요구**한다. `ml-logistic-regression`은 첫 문장에 sigmoid를 쓰는데 정의 문항이 dl에 있고 이 덱에 dl이 없다.
- 신규 ai-system 기초 3문항은 `ai-basics` 카테고리(ml/llm/agent)에 ai-system이 없어 **초심자에게 노출되지 않는다.**
- 직장인 유형은 난이도 3개를 모두 받아 109문항(advanced 48)을 받거나, 자신을 "AI 입문자"로 강등해 15문항을 받거나 둘뿐이다.
- `career-switch`에 transformer가 없어 신규 transformer 10문항이 이직 준비생에게 노출되지 않는다.
- 난이도 역전 26건 중 11건이 신규 문항이 만든 것이다.

### 중복

agent 19문항 중 7개(37%)가 메모리다. `agent-memory-write-policy` 본문의 한 문장이 `agent-memory-forgetting-update` 전체 내용이다. 평가 7문항, 비용·지연 4문항, 컨텍스트 예산 4문항도 겹친다.

### 용어

신규 61문항의 영문자 비율 0.092 vs 기존 0.333. trace/span, cascade, guardrail, lost in the middle, Chinchilla가 본문에 없다. 면접 준비 앱인데 면접관이 쓸 단어가 답변 스크립트에 없다.
