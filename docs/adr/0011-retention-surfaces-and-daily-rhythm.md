# ADR 0011: 재방문을 만드는 화면과 하루의 리듬

- Status: Accepted
- Date: 2026-08-21

## Context

standalone HTTPS 배포로 앱을 언제든 열 수 있게 됐지만, 다시 열 이유는 앱 안에 거의 없었다. 확인해보니 몇 가지가 겹쳐 있었다.

- `calculateStreak`가 오늘부터 거꾸로 세어, 오늘 아직 학습하지 않은 아침에는 열흘 연속 기록도 `0`으로 보였다. 기록을 이어갈 동기가 가장 필요한 순간에 정반대로 작동했다.
- 세션을 마친 화면이 정적인 축하 문구로 끝나, 가장 주목도가 높은 순간에 다음에 올 이유를 말하지 않았다.
- 밀린 복습 수는 계산되고 있었지만 시작 버튼 라벨 안에만 묻혀 있었다.
- `activityDates`에 1년치가 쌓이는데 연속 일수 계산 외에는 쓰이지 않았다.
- 레벨 구간이 균등해서 첫 레벨업까지 `알았다` 40문항이 필요했다. 시작한 사람이 성취를 한 번도 보지 못하고 떠나는 구간이 길었다.
- 공유 버튼은 받는 사람이 열 수 없는 WebView 내부 URL 때문에 숨겨져 있었고, 그 전제가 HTTPS 배포로 사라졌는데도 그대로였다.

## Decision

- `calculateStreak`는 오늘 학습 전이면 어제까지의 연속 기록을 돌려준다. 오늘이 비었다는 사실은 `hasStudiedToday`로 분리해 알린다. 하루를 통째로 건너뛰면 종전대로 끊긴다.
- 하루 목표를 5문항으로 두고 홈에 원형 게이지로 보여준다. 오늘 몫은 날짜별 집계를 새로 저장하지 않고 각 문항의 `lastReviewedAt`에서 센다.
- 연속 기록은 불꽃으로 표시한다. 기록이 없으면 꺼져 있고, 앱을 쓰는 동안 하루가 늘어난 순간에만 한 번 터진다. 처음 불러온 값은 축하 대상이 아니다.
- 세션 완료 화면이 연속 일수, 다음 레벨까지 남은 점수, 내일 복습할 개념 수, 이번 세션 평균 유사도와 기록 경신 수를 보여준다.
- 레벨 경계를 `0 / 4 / 12 / 30 / 60`으로 앞을 촘촘하게 바꾼다. 첫 레벨업이 한 세션 안에 나오고, 최고 레벨은 여전히 멀다. 점수 계산식은 그대로 둔다.
- 레벨이 오르는 순간에만 전체 화면 축하를 띄운다. 점수가 1점 오르는 것과 레벨이 바뀌는 것은 무게가 다르다.
- `activityDates`를 최근 70일 달력으로 기록 화면에 보여준다.
- `AppBadge` port로 밀린 복습 수를 설치된 앱 아이콘 배지에 올린다. 설치하지 않았거나 지원하지 않으면 어댑터가 조용히 넘긴다.
- 답이 열리기 전 마지막 5초를 색과 소리로 알린다(`CountdownCue`). 소리는 `SoundPreference`로 끌 수 있고, 꺼도 시각적 카운트다운과 잠금은 그대로다.
- 공유 버튼을 되살린다. 링크는 현재 주소에서 query와 hash를 뗀 값이라 GitHub Pages 주소가 그대로 나간다.
- 발화 기록(`bestSimilarity`, `missedKeyPoints`)을 도서관 카드의 추이와, 지난번 놓친 포인트를 이번에 말했을 때의 안내로 쓴다.

## Consequences

- 아침에 앱을 열었을 때 연속 기록이 사실대로 보이고, 오늘 칸이 비어 있다는 것이 따로 드러난다.
- 하루 목표와 달력이 "오늘 뭘 하면 되는지"와 "얼마나 이어왔는지"를 각각 맡는다. 홈 히어로에 있던 오늘 완료 칩은 링과 중복이라 뺐다.
- 레벨 경계를 바꿔 기존 사용자의 표시 레벨이 올라간다. 점수 자체는 그대로이므로 데이터 이전은 필요 없지만, 바뀐 직후 한 번 레벨업 축하가 뜰 수 있다.
- 배지와 소리는 둘 다 부가 신호다. 실패하거나 지원되지 않아도 학습 흐름을 막지 않는다.
- 진짜 푸시 알림은 여전히 없다. 서버(VAPID)가 필요해 ADR 0001의 local-first 전제와 충돌하므로, 필요해지면 별도 ADR로 다룬다.
- 공유가 열리면서 외부 유입 경로가 처음 생겼다. OG image와 share card는 아직 없어 링크 미리보기는 기본값이다.
